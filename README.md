# Light of Gospel Community Church Website

## Project Description

Light of Gospel Community Church is a fictional church website developed as part of an HTML web development assignment.

The website provides information about the church, its beliefs, worship services, ministries, blog articles, contact information, and membership application process.

The project uses HTML only, without CSS or JavaScript.

## Pages Included

1. index.html: Church homepage
2. about.html: Church history, beliefs, and leadership
3. services.html: Weekly services and ministries
4. blog.html: Church articles and updates
5. contact.html: Contact information and enquiries
6. pages/application.html: Membership application

## HTML Features Used

- Semantic HTML elements
- Headings and paragraphs
- Ordered and unordered lists
- Description lists
- Internal and external links
- Relative and fragment links
- Email and telephone links
- Images with alternative text
- Figure and figcaption
- Data tables with captions and headings
- Accessible form controls
- Fieldset and legend
- HTML validation
